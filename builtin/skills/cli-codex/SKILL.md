# Codex CLI (cli-codex)

## 定位与概述
Codex CLI 是 OpenAI 提供的命令行代码辅助工具（npm 包 `@openai/codex`），对应本机主命令 `codex`。
本技能为 Agent 提供调用 `codex` 命令行工具的规范指导，协助完成代码片段生成、审查与一次性自动化任务。

## 命令与参数规范
- 主执行命令：`codex`
- 一次性执行子命令与参数：
  - `codex exec "<prompt>"`：以一次性非交互模式执行提示词任务，输出生成或分析内容后立即退出。
  - `codex --help`：查看当前已安装版本的帮助信息。
- 示例：
  ```bash
  codex exec "分析当前目录中最近修改的源文件并给出优化建议"
  ```

## 一次性调用规范（重要纪律）
1. **严格禁止交互式会话**：严禁直接运行裸命令或进入交互式 REPL 会话。Agent 必须通过 `exec` 等一次性子命令或参数传递完整任务指令，命令执行完成后立即退出并回传结果。
2. **遵守调用超时约束**：CLI 服务配置了单次调用超时时间（默认 120 秒，可配置范围 10-600 秒）。执行超时将被系统强制终止，请避免在单次一次性调用中提交超大规模或无限循环任务。
3. **环境变量与凭据**：执行环境变量由系统安全快照按需注入，无需且严禁在命令行明文传递 API Key。
