# 08 — 飞书入口的"命令支持"：命令集与解析方式

- **Type**: grilling
- **Mode**: HITL
- **Status**: resolved
- **Blocks**:
- **Blocked by**:

## Question

用户提出飞书入口"不止是流式输出，可能还有命令的支持"。需要定：

- **命令形态**：斜杠命令（如 `/status <id>`、`/run <flow>`、`/list`）作为确定性入口，还是纯自然语言对话解析，还是两者并存（命令兜底/快捷方式）？
- **命令集范围**：第一版有哪些命令（查询类：执行状态/项目/flow；任务类：下发/取消）？与对话能力的边界（命令是对话能力的一个子集还是独立通道）？
- **命令在飞书里的表达**：飞书是否支持斜杠命令 UI（应用菜单/快捷指令）还是纯文本解析？

## Resolution

2026-08-02 用户拍板：

1. **形态：双轨**——斜杠命令 = 确定性直通（不走 LLM，直接调 CLI + 格式化结果）；自然语言走 PI agent（自由表达，工具面 = CLI 全量除 release）。
2. **命令集（MVP）**：查询类 `/status <id>`、`/list`；会话类 `/reset`、`/help`。**下发（/run）与取消（/cancel）不列入命令集**：下发走自然语言（agent 理解 → task run 工具）；取消执行能力 MVP 不提供（闭环 03 备注①）。
3. **呈现：飞书指令菜单**——配置飞书应用指令（输入 `/` 弹出菜单）。该能力与配置成本需在 story 的 tech-design 阶段以官方文档验证；若飞书不支持或成本过高，降级纯文本解析（同通道接收）。
