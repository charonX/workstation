会话淘汰重构方案

基于当前实现，我建议按以下三点收敛：

1. 淘汰三触发统一到模块

  • TTL 1h：sweep 60s 周期扫描
  • LRU 50：新会话到达时淘汰最久未活动
  • 同组单活：活动即冷却组内其他
关键约束：流式/队列中的会话永不淘汰——任务不会因切换被掐断。

2. 核心实现

// 豁免判定：流式/队列中不淘汰
function isExempt(entry) {
  return entry.streaming || entry.queued;
}
const evicted = collectIdle(sessions, t - TTL_MS)
  .filter(k => !isExempt(sessions.get(k)));
// 淘汰：dispose + 辅助 Map×3 清理 + tombstone
evicted.forEach(evict);
