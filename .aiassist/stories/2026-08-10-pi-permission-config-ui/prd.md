# PI 权限策略可视化管理（Permission Config UI）

## 1. 问题陈述

PI agent 的权限策略目前只活在**代码/JSON 文件**里：全局出厂策略（`agent-policy/pi-permission-config.json`，真源为代码规则表 `policyRules.js`）在 UI 中零呈现；项目级策略（`<projectDir>/.pi/extensions/pi-permission-system/config.json`）只能**手写 JSON**，无脚手架、无可视化、无校验。用户无法在界面中回答两个基本问题：「这个项目里 agent 能干什么？」「哪些操作会弹确认卡？」，更无法调整——项目变多后逐项目手写 `.pi` 文件不可持续。

## 2. 解决方案

在**管理区项目详情弹窗**内新增「权限配置」页签：

- **继承视图**：面板呈现「全局基底 + 项目覆盖高亮」的完整生效形态——全局规则（来自代码规则表渲染）只读展示为基底；项目自己的覆盖条目标注「项目已改」；
- **全量面板化**：`pi-permission-config.json` 全字段域可视化——bash 高危规则族（删除/提权/杀进程/磁盘/重定向/管道等，按 family 分组）、工具级裁决（read/write/edit/… → allow/ask）、全局兜底（`"*"`）、path 白名单、外部目录、authorizerChain、其他开关（yoloMode/debugLog/doublePressToConfirm/预览长度）；
- **JSON 高级模式兜底**：可切换到 JSON 直接编辑；面板保存时**保留面板不认识的字段**（单向同步，JSON 为自由区）；
- **首次编辑时生成**：项目创建不预置 `.pi` 文件；UI 首次保存时生成（模板 = 全量跟随全局的初始形态）；
- **保存即生效**：写入 `.pi` 文件后，gotgenes 下次评估自动按新配置执行（mtime stamp 缓存实证，无需自造热重载）；
- **保存校验 fail-closed**：JSON 语法 + schema 校验，非法拒绝落盘并报错定位；项目文件保持上次合法状态。

## 3. 用户故事

1. 作为**本机用户**，我想要在项目详情里看到「这个项目 agent 能干什么」——全局规则 + 项目覆盖一目了然，以便不用读代码/JSON 就理解权限。
2. 作为**本机用户**，我想要在 UI 中调整项目权限（如把 `rm *` 从允许改为询问、把 write 从询问改为允许），以便不再手写 JSON。
3. 作为**本机用户**，我想要保存后新规则立即生效（下一条命令按新策略评估），以便快速验证配置效果。
4. 作为**维护者**，我想要项目配置只覆盖我要改的项、未改项干净继承全局，以便不会因复制全局模板产生伪差异。
5. 作为**维护者**，我想要 JSON 高级模式里手写的自定义字段不被面板保存冲掉，以便两种编辑方式共存不打架。
6. 作为**维护者**，我想要保存时校验拦截非法配置，以便运行中的 agent 不受坏配置影响。

### F1 查看项目权限（B1/B2/B3）

## 10. 实现决策（高层，不写代码）

### 10.1 模块边界与解耦

- **渲染层新增「权限配置」页签组件**（项目详情弹窗内）：继承视图面板（全局基底只读 + 项目覆盖高亮）+ JSON 模式切换 + 保存；纯展示/编辑组件，经 HTTP API 读写，不直接碰文件系统。
- **主进程服务层新增权限配置 API 面**：读（项目继承视图组装：全局规则表渲染 + 项目覆盖合并）、写（校验 + 原子写 `.pi` 文件）、校验（JSON 语法 + schema）；与 `policyRules.js`（真源）、`permissionPolicy.js`（工具默认裁决）同源消费，不重复实现规则语义。
- **全局只读数据源 = 部署 JSON**（`agent-policy/pi-permission-config.json`）——运行时真相（代码规则表经生成器产出，UI 直接展示执行面；BASH_RULES 仅作 family/可读文案的元数据注入源，Q1/Q6 拍板）。
- **保存即生效零自造**：gotgenes policy-loader 每次评估 stat 文件（mtime stamp），写文件即生效——不引入 watcher/重载通知（实证：policy-loader.ts getFileStamp）。
- **原子写**：临时文件 + rename 落盘，失败不污染现有文件。
- **schema 校验器来源**：gotgenes 包内 `schemas/permissions.schema.json`（本地，离线可用）——E4 降级路径仅作防御。

### 10.2 关键约束

- ADR-020 不动：全局策略**只读展示**，真源仍是代码规则表。
- ADR-017 不动：授权桥/确认卡运行机制不变。
- `.pi` 文件仍是运行时真相（gotgenes cwd 发现路径），无独立 DB 状态。
- 既有 REQ-AGENT-033「设置页无权限 tab」断言：入口在**项目详情弹窗**（管理区），不新增 Settings tab——需确认该断言是否触碰（弹窗 vs 设置页为不同 locator 面）。
- MCP 不进本期（单独立项）；gotgenes 的 `getConfiguredMcpServerNames` 接口与后续 MCP story 相关，本期不消费。
